# 🎓 CampusFlow-ERP
### Integrated University Enterprise Resource Planning System

CampusFlow-ERP is a lightweight, integrated Enterprise Resource Planning (ERP) prototype designed for the higher education sector. It aims to streamline university operations by connecting essential academic and administrative processes through a unified platform.

The system integrates student management, course registration, attendance tracking and examination management to improve administrative efficiency, reduce data redundancy and simplify academic information management.

**Project Type:** Academic Team Project  
**Institution:** NSBM Green University  
**Project Status:** Academic Prototype

---

## 🎯 Project Objectives

- Digitalise essential university administrative processes.
- Centralise student and academic information.
- Simplify course registration and attendance tracking.
- Organise examination records and student results.
- Improve data consistency across academic modules.
- Demonstrate an integrated ERP architecture for higher education.

---

## ✨ Core System Modules

### 1. Student Management
- Manage student profiles and personal information.
- Centralise student-related academic records.
- Organise student information within a unified system.

### 2. Course Registration
- Manage student course registrations.
- Associate students with relevant academic modules.
- Maintain course-related registration information.

### 3. Attendance Management
- Track daily lecture attendance.
- Maintain student attendance records.
- Calculate attendance eligibility metrics.

### 4. Examination Management
- Record and update examination marks.
- Organise examination information by course.
- Maintain student examination records.

## 🏗️ System Architecture

CampusFlow-ERP follows an integrated architecture connecting the frontend, backend and relational database.

```text
                 USERS
                   |
                   v
            WEB APPLICATION
                   |
                   v
             FRONTEND LAYER
                   |
                   v
              BACKEND LAYER
                   |
                   v
           RELATIONAL DATABASE
                   |
        +----------+----------+
        |          |          |
        v          v          v
     STUDENT     COURSE    ATTENDANCE
   MANAGEMENT  REGISTRATION MANAGEMENT
                   |
                   v
          EXAMINATION MANAGEMENT
```

The architecture is designed to support communication and data relationships across the four core university modules.
